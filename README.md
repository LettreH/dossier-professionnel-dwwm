# Dossiers de soutenance – Titre Professionnel DWWM

Ce dépôt regroupe mes documents de soutenance pour le **Titre Professionnel Développeur Web et Web Mobile** (RNCP 37674).

Il ne contient pas le code source des projets (voir les liens plus bas). Il rassemble les documents utilisés pour l'évaluation : dossier professionnel, dossier de projet et présentation orale.

## Comment lire les documents

1. Commencer par le **Dossier professionnel** : il montre ma pratique sur plusieurs projets de la formation.
2. Continuer avec le **Dossier de projet** : il détaille un projet complet, de l'analyse du besoin jusqu'à la mise en ligne.
3. La **Présentation** reprend les points clés du dossier de projet pour l'oral.

## Compétences du titre

**CCP 1 – Développer la partie front-end d'une application web ou web mobile sécurisée**

- CP1 – Installer et configurer son environnement de travail en fonction du projet web ou web mobile
- CP2 – Maquetter des interfaces utilisateur web ou web mobile
- CP3 – Réaliser des interfaces utilisateur statiques web ou web mobile
- CP4 – Développer la partie dynamique des interfaces utilisateur web ou web mobile

**CCP 2 – Développer la partie back-end d'une application web ou web mobile sécurisée**

- CP5 – Mettre en place une base de données relationnelle
- CP6 – Développer des composants d'accès aux données SQL et NoSQL
- CP7 – Développer des composants métier côté serveur
- CP8 – Documenter le déploiement d'une application dynamique web ou web mobile
